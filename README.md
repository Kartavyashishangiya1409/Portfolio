# Portfolio Website

This is a personal portfolio website built with HTML, CSS, and Tailwind CSS. It showcases projects, skills, and experience.

## 🚀 Live Demo
[Click here to view the portfolio](https://portfolio-kartavya-shishangiyas-projects.vercel.app)

## 📌 Features
- Responsive design
- Interactive UI with Tailwind CSS
- Projects showcase
- Contact section

## 🛠️ Technologies Used
- HTML
- CSS
- Tailwind CSS
- JavaScript

## 📂 Folder Structure
```
Portfolio/
│── assets/            # Images and other assets
│── index.html         # Main HTML file
│── style.css          # Custom CSS styles
│── tailwind.config.js # Tailwind CSS configuration
```

## 🔧 Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/Kartavyashishangiya1409/Portfolio.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Portfolio
   ```
3. Open `index.html` in your browser or use Live Server for best experience.
